# Offline map

The radar can draw **coastlines, runways and airport codes** under the
aircraft. The map is compiled into the firmware for your area, so it works
without internet. It is generated by `tools/gen_map.py` into `main/map_data.c`
(ignored by git — it's specific to your location). Without it the radar shows
only rings and aircraft.

## Data sources

| Data | Source | Licence |
|---|---|---|
| Airports and runways | [OurAirports](https://ourairports.com/data/) `airports.csv`, `runways.csv` | Public domain |
| Coastlines, standard | [Natural Earth](https://www.naturalearthdata.com/) 10 m coastline (~1 km detail) | Public domain |
| Coastlines, detailed (optional) | [OpenStreetMap](https://www.openstreetmap.org/) `natural=coastline` (~10 m detail) | ODbL — the display shows "© OpenStreetMap" |

## Generate the map

1. Download the public-domain files into one folder:

    ```bash
    curl -L -o ne_10m_coastline.geojson https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_10m_coastline.geojson
    curl -L -o ne_10m_minor_islands_coastline.geojson https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_10m_minor_islands_coastline.geojson
    curl -L -o airports.csv https://davidmegginson.github.io/ourairports-data/airports.csv
    curl -L -o runways.csv https://davidmegginson.github.io/ourairports-data/runways.csv
    ```

2. Optional, for detailed coastlines: fetch OpenStreetMap coastlines for a
   bounding box around your receiver (south, west, north, east) from the
   Overpass API. Keep the box reasonable — a few degrees each way:

    ```bash
    curl -A "esp32p4-adsb-display map generator" -o osm_coast.json \
      --data-urlencode 'data=[out:json][timeout:180];way["natural"="coastline"](49.5,-3.5,53.5,2.5);out geom;' \
      https://overpass-api.de/api/interpreter
    ```

3. Generate (example for a receiver near London Heathrow):

    ```bash
    python tools/gen_map.py --lat 51.4700 --lon -0.4543 --radius 400 --data <folder> \
      --osm-coast <folder>/osm_coast.json --tol 0.00006
    ```

    `--radius` is in nautical miles; `--tol` is the simplification tolerance in
    degrees (0.00006 ≈ 7 m). Leave out `--osm-coast` to use Natural Earth.

4. Rebuild and flash/OTA the firmware.

## What's drawn when

| Item | Shown |
|---|---|
| Coastlines | always (points closer than 2 px are skipped when zoomed out) |
| Runways | large/medium airports always; small strips at ≤ 40 nm range |
| Airport codes | large airports always; medium ≤ 120 nm; small ≤ 40 nm |

Tap the picture button on the radar to hide the map.
